# Topic summary document sources

This directory is the public, editable expanded-reference source area for the
paired PDF and DOCX topic summaries. It remains independent from the
exercise-and-solution pipeline under `download-sources/`, while the concise
opening section is intentionally shared with each Quarto website Summary tab.
Keeping these sources in the repository lets a future contributor inspect and
regenerate the learner documents instead of treating the PDF and DOCX files as
unexplained binaries.

Each download has two maintained Markdown inputs per topic and locale. The
concise input at `../topic-summaries/{locale}/t{NN}.md` is also the source of the
corresponding website Summary tab. The expanded input in this directory retains
the existing six-section study reference and stable filename stem. The renderer
places the concise course-page summary first, then the expanded reference, a
small raster Ratiomera mark, and exactly three lined note pages.

The wrapper gives both parts localized H1 labels. It promotes the concise
fragment's website H3 subsection headings to H2 in the document only, preserving
their wording, order, formulas, tables, and prose. The expanded source continues
to supply its six H2 sections and exactly one registered local explanatory PNG.
Neither input may contain executable code, raw output, includes, remote
resources, file traversal, HTML, links, or SVG content. The concise shared
fragment also cannot contain images or em dashes.

Directory ownership:

- `en/` contains the canonical US English sources;
- `de/` contains the natural academic German sources for Switzerland;
- `sq/` contains the natural standard Albanian adaptations with informal
  singular learner address, adapted directly from canonical English;
- `assets/{locale}/` contains only the allowlisted raster logo and explanatory
  figures generated by `scripts/generate-summary-assets.R`.

The current implementation contains the finalized canonical English expanded
set and machine-validated de-CH and Albanian adaptations. The localized sets
remain pending the human and native-speaker review recorded in the parity
manifest. Do not start a localized source from an unfinished English document.
Generated PDF and DOCX files are staged under the matching locale's
`downloads/files/` directory, but this pipeline does not alter `downloads.yml`,
the topic-page wrappers, or publication status. Updating a shared concise
fragment changes both the website Summary tab and the opening part of the next
generated download.
The summary system uses PNG assets only and produces PDF and DOCX outputs.
Obsolete SVG summaries are outside the system and must not be recreated.
The generated formats share one owned table contract: stable topic-specific
column proportions, full A4 text width, readable header hierarchy, explicit
padding and rules, and protected rows/captions. All locales use an 11-point
body setting, and every document ends with exactly three lined note pages.

Run the English workflow from the project root:

```bash
Rscript scripts/generate-summary-assets.R
python3 scripts/validate-summary-documents.py --locale en --sources-only
python3 scripts/render-summary-documents.py --locale en
python3 scripts/validate-summary-documents.py --locale en
PYTHONDONTWRITEBYTECODE=1 python3 scripts/test-summary-documents.py
```

Run the German workflow only after English passes:

```bash
Rscript scripts/generate-summary-assets.R --locale de
python3 scripts/validate-summary-documents.py --locale de --sources-only
python3 scripts/render-summary-documents.py --locale de
python3 scripts/validate-summary-documents.py --locale de
PYTHONDONTWRITEBYTECODE=1 python3 scripts/test-summary-documents.py
```

Run the Albanian workflow only after English and German pass:

```bash
Rscript scripts/generate-summary-assets.R --locale sq
python3 scripts/validate-summary-documents.py --locale sq --sources-only
python3 scripts/render-summary-documents.py --locale sq
python3 scripts/validate-summary-documents.py --locale sq
PYTHONDONTWRITEBYTECODE=1 python3 scripts/test-summary-documents.py
```

Do not hand-edit generated PDF, DOCX, logo, or explanatory PNG files. Update the
concise shared Summary-tab Markdown, the expanded reference Markdown, or the
trusted shared R plot source as appropriate, then regenerate and validate.
