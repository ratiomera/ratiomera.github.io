# Ratiomera

Ratiomera is a multilingual, volunteer-built learning platform for clear,
rigorous, and practical education in statistics and mathematics. It connects
careful explanations with meaningful examples, guided practice, complete
solutions, and downloadable learning materials. Everything is available
without an account, subscription, or paywall.

Public website: [ratiomera.ch](https://ratiomera.ch)

> **Project status: In Review**
>
> Ratiomera Statistics is undergoing content, language,
> accessibility, and publication review. Material may still change as errors
> are corrected and explanations are improved. Ratiomera Mathematics remains
> planned.

## Two Educational Branches

Ratiomera has two educational branches. Within this project, a branch is one
of the platform's subject areas.

### Ratiomera Statistics

Ratiomera Statistics is the active branch. It provides university-level
statistics education for the humanities and social sciences, including fields
such as psychology, education, sociology, political science, and public health.

Its current Introduction to Statistics sequence moves from descriptive
statistics and probability through statistical inference, correlation,
regression, and analysis of variance. Each topic combines conceptual theory,
simulated examples, exercises with complete solutions, a summary, and
downloadable PDF and Word materials.

### Ratiomera Mathematics

Ratiomera Mathematics is a planned future branch. Its long-term aim is to
develop a coherent learning path from primary-school mathematics through Swiss
Gymnasium level. No Mathematics lessons are currently available.

## Languages

Ratiomera currently supports:

- English
- German for Switzerland (`de-CH`)
- Albanian (`sq`)

English is the canonical development language. The German and Albanian
versions follow the same learning sequence, calculations, notation, figures,
exercises, solutions, and learning goals while adapting the wording to each
linguistic and educational context. Language review remains part of the current
publication review.

## Open Access and Voluntary Work

Ratiomera is currently developed and maintained entirely through voluntary
work. The project charges no course fee or subscription and currently accepts
no donations.

The learning path is intended to remain available without mandatory accounts,
premium tiers, paid answer keys, locked exercises, or required purchases.
Contributions of subject knowledge, teaching experience, language review,
accessibility expertise, design, and technical development can all help the
project improve.

## Responsible Use

Ratiomera is designed to accompany teaching, assigned readings, official
curricula, assessment requirements, and guidance from a school, university, or
instructor. If it differs from material officially provided in a course, the
institution's guidance takes priority, and learners should ask the responsible
teacher or lecturer.

The contributors work carefully toward accuracy, but the material may contain
errors or incomplete explanations, particularly while it remains in review.
Constructive corrections and clearly described problems are welcome.

## Repository and Publication

Ratiomera is built with [Quarto](https://quarto.org/). The editable source files
live outside `docs/`, which contains the generated static website intended for
GitHub Pages. Changes belong in the source files; a render updates `docs/`. The
public build is designed to work without API keys, access tokens, or private
credentials.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a content,
language, accessibility, design, or technical change. It explains the source
of truth, multilingual editing order, repository structure, and required
validation checks.
