# Ratiomera Logo System

## Selected direction

The selected mark is **Measured R**. An open geometric R establishes the
Ratiomera initial, while the short interval inside its upper form represents
comparison, measurement, and the connection between an observation and its
interpretation. The open counter keeps the symbol approachable and readable at
favicon size. The mark works without color and does not depend on a
subject-specific cliché.

## Core assets

- `ratiomera-logo-primary.svg`: primary horizontal lockup.
- `ratiomera-logo-stacked.svg`: compact stacked lockup for square or centered layouts.
- `ratiomera-mark.svg`: umbrella icon in Ratiomera navy.
- `favicon.svg`: reversed mark on a navy tile.
- `ratiomera-logo-light.svg`: standard logo for light backgrounds.
- `ratiomera-logo-dark.svg`: white logo for dark backgrounds.
- `ratiomera-logo-mono.svg`: single-color production version.
- `ratiomera-statistics-mark.svg`: umbrella mark with the Statistics accent.
- `ratiomera-mathematics-mark.svg`: umbrella mark with the Mathematics accent.

## Color

| Role | Hex | Use |
|---|---:|---|
| Ratiomera navy | `#183B56` | Umbrella identity, wordmark, primary interface accents |
| Statistics blue | `#2F6F9F` | Restrained Statistics branch accent only |
| Mathematics copper | `#B46124` | Restrained Mathematics branch accent only |
| White | `#FFFFFF` | Reversed artwork on dark surfaces |

Branch color is deliberately limited to one side of the shared mark. This keeps both branches visibly related to Ratiomera and avoids turning navigation into a collection of unrelated logos.

## Usage rules

- Use the full horizontal logo when the wordmark must introduce the project.
- Use the mark beside an adjacent text label in compact headers, as the website does.
- Keep clear space around the mark equal to at least one quarter of its width.
- Do not stretch, rotate, outline, add shadows, recolor individual pieces, or place the standard navy artwork on a low-contrast background.
- Do not replace the umbrella mark with the Statistics or Mathematics variant on project-wide pages.
- The production wordmark is built from vector paths, so it does not depend on an installed font and remains stable in print and PDF workflows.

## Accessibility

When a nearby visible label already says “Ratiomera,” the mark is decorative and should use empty alternative text. When the logo is the only brand label, use alternative text that names the relevant identity, such as “Ratiomera Statistics.”
